# 输出格式规范

> 简洁为主（对齐本仓库 find-information 的风格），但**安全措辞完整**。
> 所有输出末尾必须有免责声明；涉及自身症状时必须显式给出置信度。

---

## 形态 A：完整问诊输出

```
## ⚠️ 急症提示（仅当命中红旗时出现）
（命中话术，见 red-flags.md；此后不再输出鉴别诊断）

## 症状摘要
一句话主诉 + 已确认的关键维度（部位/性质/持续时间/严重度等），如：
"反复头晕约 2 周，视物轻微旋转感，休息可缓解，程度 4/10。"

## 可能的原因（鉴别诊断参考）
| 可能情况 | 置信度 | 依据 | 建议 |
|---|---|---|---|
| 需要排出的严重情况（若有） | 低/中/高 | 症状对应的红旗或危险信号 | 立即或尽快就医 |
| 常见可能 1 | 中 | 症状详情页/疾病详情页匹配点 | 观察或就医 |
| 常见可能 2 | 低 | 症状部分匹配 | 就医确认 |
| 少见/需检查排除 | 低 | 不足以排除 | 检查后确认 |

- 按「需排出的严重情况 → 常见可能 → 少见」分层。
- 置信度显式标注（高/中/低）并给一句依据；没有把握就写低。
- 措辞一律「可能是 / 需要排除 / 建议就医确认」，**不下确诊结论**。

## 就医建议
- 是否需要就医：观察 / 建议近期就医 / 尽快就医
- 建议科室：如全科、神经内科、耳鼻喉科等（参考 dayi 疾病详情页「就诊科室」）
- 就诊前准备：带什么资料（近期检查、用药清单、症状时间线）

## 去看医生时你可以问的问题
1. …
2. …

## 来源
- [dayi 症状页] 头晕 — https://www.dayi.org.cn/symptom/1143957
- [dayi 疾病页] xxx — https://www.dayi.org.cn/disease/{id}

> ⚠️ 以上内容仅供健康信息参考，不构成医疗诊断或治疗建议；如有急症请立即就医。
```

## 通用规则

1. **免责声明必带**：每条输出末尾附上标准句式（见模板）。
2. **不确诊、不处方**：始终用"可能是/需要排除/建议就医确认"；不替用户决定用药。
3. **置信度显式**：鉴别诊断每个候选标高/中/低 + 依据。
4. **不确定性不藏**：信息不足时说"还需要了解 X 才能更好判断"，而不是硬凑答案。
5. **中西医分开**：涉及中医病机时标注"中医角度"，与西医病因并列呈现。
6. **来源可追溯**：引用 dayi 时给详情页 URL，用户可自行核对。
