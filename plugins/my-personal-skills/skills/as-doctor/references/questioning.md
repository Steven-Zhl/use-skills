# 症状采集框架（现病史 HPI）

> 目标：像医生一样**对话式**采集，而不是问卷轰炸。每次只问 1–2 个问题，用大白话。

---

## OLDCARTS（完整版）

| 维度 | 含义 | 提问示例（大白话） |
|---|---|---|
| **O**nset 起病 | 何时开始，骤起还是渐进 | "什么时候开始的？突然出现的还是慢慢加重的？当时在做什么？" |
| **L**ocation 部位 | 具体位置 | "具体在哪个位置最明显？能不能指一下？" |
| **D**uration 持续时间 | 持续多久了 | "这个情况持续多长时间了？" |
| **C**haracter 性质 | 感觉是什么样 | "是一种什么样的感觉？（胀、痛、烧灼、针刺、麻木…）" |
| **A**ggravating 加重因素 | 什么情况下更重 | "什么情况下会更难受？" |
| **R**elieving 缓解因素 / Radiation 放射 | 什么能缓解 / 往哪扩散 | "什么能让它好一点？会不会往别处（比如胳膊、后背）蔓延？" |
| **T**iming 时间规律 | 持续还是时好时坏 | "是一直都有，还是一阵一阵的？有没有特定时间（比如晚上）更明显？" |
| **S**everity 严重度 | 0–10 分 | "如果用 0 到 10 打分，10 是最难受，现在是几分？" |

## OPQRST（简化版，急性疼痛/不适时优先）

Onset 起病 → Provocation/Palliation 诱因与缓解 → Quality 性质 → Region/Radiation 部位与放射 → Severity 严重度 → Time 时间规律。

---

## 分支问题（按需补充，不要全问）

- **功能影响**：影响吃饭/睡眠/工作/活动吗？（最能反映严重度）
- **伴随症状**：有没有发热、恶心、乏力、出汗、头晕等其他不适？（注意不引导性提问，问完让用户自己说）
- **既往史**：有没有高血压、糖尿病等慢性病？（优先从档案读取，缺失再问）
- **用药/过敏**：近期在吃什么药？有没有过敏史？（同上）
- **近期近况**：最近出差/旅行、饮食、作息、压力有变化吗？
- **相关检查**：近期做过什么检查（血压、化验、影像）？结果如何？

---

## 采集规则

1. **一次 1–2 问**：先问用户最先提到、最困扰的症状，逐个覆盖。
2. **用大白话**：避免"加重因素""放射痛"等术语，转成"什么情况下更难受""会不会往别处跑"。
3. **不引导**：不要问"是不是刺痛？"之类暗示性提问，先开放（"什么感觉？"），再追问。
4. **适时停止**：信息足以形成候选清单即可停，或用户表示不愿继续。不要为了凑满维度反复追问。
5. **复述确认**：采集差不多时，用一两句话复述主诉让用户确认，避免理解偏差。
