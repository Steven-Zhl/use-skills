# 急诊红旗症状清单

> **安全核心文件。** 凡涉及「自身症状」的问诊（形态 A），第一步必须按本清单排查。
> 命中任一红旗 → 立即输出命中话术，**停止后续鉴别诊断分析**，仅保留病史记录。

---

## 红旗清单（出现任一 → 立即就医 / 拨打 120）

| 症状表现 | 提示的急症 |
|---|---|
| 胸痛呈压榨/紧缩感，放射到左臂、下颌、背部，伴出汗、恶心、气短 | 心肌梗死 |
| 卒中 BEFAST：突发平衡失调 / 视物模糊 / 面部歪斜 / 一侧肢体无力 / 言语不清 | 脑卒中 |
| 突发或进行性加重的呼吸困难，口唇/指尖发绀 | 心/肺急症、肺栓塞 |
| 全身皮疹+呼吸困难+喉部发紧/吞咽困难 | 严重过敏反应（过敏性休克） |
| 无法控制的出血 | 失血性休克 |
| 意识丧失、昏迷、抽搐 | 各种危重症 |
| 突发剧烈头痛（"一生中最痛"、雷击样） | 蛛网膜下腔出血 |
| 高热 + 颈项强直（脖子僵硬） | 脑膜炎 |
| 发热/感染 + 意识模糊 + 心率快 + 呼吸急促 | 脓毒症 |
| 严重腹痛伴面色苍白、冷汗 | 急腹症 |
| 婴儿（<3 月龄）发热；孕期阴道出血 | 高危人群 |
| 明显精神状态改变或持续恶化 | 需要紧急评估 |

> 清单不穷尽。**拿不准就建议就医**——漏检比过度谨慎危险得多。

## 规则

1. 红旗快筛在所有采集**之前**进行：先问高危问题（胸痛/呼吸困难/卒中征象/意识改变），再进入常规采集。
2. 用户后续补充的信息若出现红旗 → 同样立即转入紧急处理。
3. 命中红旗仍应**写入病史**（标记 `redFlag: true`），方便后续跟进。
4. 若用户明确是替他人（家人/朋友）咨询，同样适用，并建议尽快送医。
