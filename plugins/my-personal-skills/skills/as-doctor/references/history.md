# 病史 / 患者档案读写规范

> 全局路径、工具无关：数据存在 `$HOME` 下，不放进任何 git 仓库，跨 Claude Code / Codex / Cursor 等客户端通用。

---

## 存储位置

```
~/.symptom-history/
├── patient-profile.md   # 患者档案（静态，低频更新）
└── history.jsonl        # 每次咨询记录（追加，一行一条）
```

路径约定写在 SKILL.md；用户可自行改为其他目录，改动时同步修改约定说明。

---

## patient-profile.md（患者档案）

首次形态 A 问诊时若无档案则创建，之后每次发现新信息才更新：

```markdown
# 患者档案
最后更新：YYYY-MM-DD

## 基本信息
- 年龄/性别：（可空，用户可选填）
- 其他：（身高体重/职业等，用户可选填）

## 既往病史
- 慢性病（高血压/糖尿病等）、已确诊疾病

## 过敏史
- 药物/食物过敏

## 用药史
- 长期用药、近期用药

## 手术史
- 手术名称/时间

## 其他
- 家族史、烟酒、其他健康相关
```

**更新时机**：用户问诊中提到的新过敏、新确诊、新用药、新手术 → 追加并刷新"最后更新"。

## history.jsonl（咨询记录）

每次形态 A 咨询结束，**追加一行** JSON（一个对象一行，UTF-8）：

```json
{
  "ts": "2026-08-01 14:30",
  "mode": "A",
  "complaint": "反复头晕约2周",
  "symptoms": {
    "onset": "渐进，约2周前开始",
    "location": "头部",
    "duration": "每次数分钟到数小时",
    "character": "视物轻微旋转",
    "aggravating": "劳累后加重",
    "relieving": "休息可缓解",
    "timing": "间歇性",
    "severity": "4/10",
    "function": "不影响工作",
    "concomitant": "偶有恶心"
  },
  "redFlag": false,
  "candidates": [
    {"name": "体位性低血压", "confidence": "中", "source": "dayi symptom/1143957"},
    {"name": "耳石症", "confidence": "低", "source": "dayi disease/xxxxx"}
  ],
  "advice": "建议观察1周；若持续或加重就医，建议科室：神经内科/耳鼻喉科",
  "note": ""
}
```

- `mode`: `A`=自身症状问诊（必写）；`B`=知识问答（默认不写，除非用户要求）。
- `symptoms` 按实际采集到的维度填，未采集到的字段可省略，**不要编造**。
- `redFlag`：命中红旗为 `true`，并建议在 `note` 记录处置。
- 追加用 Write 的**追加写入**（先读全文再 Write 回，或直接以 `>>` 追加，避免覆盖已有行）。

## 读写时机

| 时机 | 动作 |
|---|---|
| 形态 A 开始 | 读 `patient-profile.md` + `history.jsonl` 最近几条 → 关联既往史/用药/过敏；档案缺失则简单补问（年龄/过敏/用药） |
| 形态 A 结束 | 追加一条记录到 `history.jsonl` |
| 发现新档案信息 | 更新 `patient-profile.md` |
| 命中红旗 | 照常追加记录，`redFlag: true` |

> 读取时**只读最近 10 条左右**即可，避免把整份病史灌进上下文。

## 隐私说明

- 数据为**本地明文文件**，skill 本身不主动上传到任何外部服务。
- 敏感数据：不要放进 git 仓库、不要同步到公共网盘；注意本机文件权限。
- 用户可选择不填基本信息（年龄/性别等），不影响功能。
